
  # UAM SIAT — Sistema Integrado de Aplicación de Tests (frontend)

  Frontend del sistema UAM SIAT de la Universidad Americana. El directorio conserva el nombre histórico `bfa-digital`.

  This is a code bundle for Interfaz web para BFA Digital. The original project is available at https://www.figma.com/design/AXOK5iNZyBlRrIWZ2nPqqb/Interfaz-web-para-BFA-Digital.

  ## Running the code

  Run `pnpm install` to install the dependencies.

  Run `pnpm dev` to start the development server.

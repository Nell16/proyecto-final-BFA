# BFA Digital

Sistema de digitalización de la Batería Factorial de Aptitudes (UAM).

- `backend/` API Spring Boot (Java) + esquema PostgreSQL/Supabase. Ver `backend/README.md`.
- `frontend/` Aplicación React + Vite. Variable `VITE_API_URL` apunta a la API.
- `docs/TALLER4.md` Evidencias del Taller 4: diagrama ER, funcionalidades y pendientes.
